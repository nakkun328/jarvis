# Research design

Phase 3 で質問から検索計画を作り、ソースの収集、評価、本文の確認、複数ソース照合、矛盾検出、追加検索、統合、引用、記憶まで扱います。検索結果の見出しだけで結論を作りません。

調査レベルは memory only、quick、standard、deep、extensive とします。ソース評価には権威性、新しさ、一次性、合意、関連性を使います。引用は最低限 title、source、URL、published date、retrieved date を保持し、主張とソースを結びます。Phase 0 では Research Engine は未実装です。
